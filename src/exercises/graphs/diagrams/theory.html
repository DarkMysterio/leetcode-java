1. Graph Fundamentals

The mental model

A graph is a non-linear data structure G = (V, E), where V is the set of vertices and E is the set of edges connecting them. Graphs model relationships: networks, maps, dependencies, social connections, state transitions, and routing.

Core Graph Anatomy

Vertices, edges, paths, degree, and reachability
  • Path: a sequence of adjacent vertices.
  • Reachability: whether one vertex can be reached from another.
  • Degree: number of incident edges; in directed graphs, distinguish in-degree and out-degree.
FAANG Interview Trigger Whenever the problem describes entities plus relationships—cities and roads, courses and prerequisites, users and friendships, transformations, states, or dependencies—translate it into vertices and edges before choosing an algorithm.

2. Based on Edge Direction

One-way vs two-way relationships

Directed Graph (Digraph)

Edges are ordered pairs: (u, v)

Each edge has a specific direction. Traversal is allowed only in the arrow direction unless a reverse edge is explicitly present.

  • Models one-way roads, follows, task dependencies, and state transitions.
  • (u,v) ≠ (v,u)
FAANG Interview Trigger Recognize directed graphs in prerequisite scheduling, dependency resolution, alien dictionaries, build systems, web links, and workflow/state-machine problems.

Undirected Graph

Edges are unordered pairs: {u, v}

Edges have no direction. A connection can be traversed in both directions.

  • Models friendships, physical cables, and two-way roads.
  • {u,v} = {v,u}
FAANG Interview Trigger Use when relationships are symmetric. Typical tasks include connected components, network connectivity, clone graph, union-find, and minimum spanning trees.

RepresentationOrdered pair (u, v)Unordered pair {u, v}
TraversalOnly in the edge directionBoth directions

ExamplesOne-way roads, task dependenciesFriendships, two-way roads

3. Based on Edge Weights

Cost-aware vs hop-aware

Weighted Graph

Each edge carries a cost, distance, time, or capacity

The best path is based on the sum of edge weights—not necessarily the fewest edges.

  • Non-negative weights → Dijkstra.
  • Negative weights → Bellman–Ford.
  • All-pairs shortest paths → Floyd–Warshall.
FAANG Interview Trigger The moment a problem mentions cost, latency, distance, effort, exchange rate, or risk, inspect weight constraints before selecting the shortest-path algorithm.

Unweighted Graph

Every edge has equal implicit cost: 1

All edges are treated equally. Shortest path means the minimum number of edges.

  • BFS discovers vertices in increasing hop count.
  • The first arrival at a vertex is shortest.
FAANG Interview Trigger Use BFS for minimum moves, word transformations, grid steps, lock combinations, and any problem where every move has the same cost.

4. Based on Connectivity

Reachability across the graph

Connected Graph

A path exists between every pair of vertices

Starting from any vertex, a traversal can eventually visit every vertex.

  • One DFS/BFS from any node visits all V.
  • A connected undirected graph has exactly one connected component.
FAANG Interview Trigger Interviewers may ask you to verify connectivity before running Prim’s algorithm, or to count the operations needed to connect an entire network.

Disconnected Graph

The graph contains two or more components

Some vertices are unreachable from others. A traversal must be restarted from every still-unvisited vertex.

  • Outer loop over all vertices + DFS/BFS finds every component.
  • Isolated vertices are valid one-node components.
FAANG Interview Trigger Use multi-source BFS when all sources begin simultaneously; use an outer traversal loop for islands, provinces, components, disconnected grids, and forest problems.

5. Cycles, Acyclic Graphs, and DAGs

Revisiting a start vertex

Cyclic Graph

Contains at least one cycle

A cycle starts and ends at the same vertex, without repeating intermediate vertices or edges.

FAANG Interview Trigger Look for deadlocks, circular dependencies, duplicate work, infinite traversal, and whether a graph can be a tree.

Acyclic Graph

Contains no cycles

No path can return to its start through distinct edges. An undirected connected acyclic graph is a tree.

FAANG Interview Trigger Acyclic structure enables simpler dynamic programming, unique parent relationships, and V−1 edge checks.

Directed Acyclic Graph (DAG)

Directed edges, no directed cycle

A directed graph with no directed cycles. At least one topological ordering exists.

FAANG Interview Trigger Use DAG + topological sort for course schedules, build order, dependency execution, spreadsheet formulas, and dynamic programming over ordered states.

6. Structural Graph Families

Recognizable invariants

Complete Graph

Every pair of distinct vertices is adjacent

For an undirected complete graph Kₙ, every vertex has degree n−1 and E=n(n−1)/2.

FAANG Interview Trigger Complete connectivity often makes explicit graph construction too expensive; reason combinatorially or generate edges lazily.

Bipartite Graph

Vertices split into two disjoint sets

No edge connects vertices inside the same set. An undirected graph is bipartite exactly when it is 2-colorable, equivalently when it has no odd cycle.

FAANG Interview Trigger Recognize team partitioning, matching, worker–job assignment, course–student relations, and “possible to split into two groups?” questions.

Tree

Connected + acyclic

A tree with V vertices has exactly V−1 edges and exactly one simple path between any two vertices.

FAANG Interview Trigger Exploit the absence of cycles: parent tracking can replace a full visited structure, and many problems reduce to postorder/subtree dynamic programming.

7. Dense vs Sparse Graphs

Representation follows edge count

Dense Graph

Number of edges approaches the maximum

When E is close to V², adjacency matrices become reasonable and edge existence checks remain O(1).

FAANG Interview Trigger For small, dense state spaces or all-pairs algorithms, a matrix may be simpler and faster in practice than nested hash structures.

Sparse Graph

Most possible edges do not exist

When E ≪ V², adjacency lists store only real edges and use O(V+E) memory.

FAANG Interview Trigger Most interview graphs are sparse. Default to adjacency lists unless constraints or required operations clearly favor a matrix.

8. Graph Representations

Choose for the operations you need

The representation determines memory cost and the complexity of edge lookup, neighbor iteration, insertion, and deletion.

Adjacency Matrix

A V × V grid
  • Space: O(V²)
  • Edge lookup: O(1)
  • Neighbor traversal: O(V)
  • Store weight instead of 1 for weighted graphs.
FAANG Interview Trigger Pick a matrix for dense graphs, constant-time edge queries, transitive closure, Floyd–Warshall, or when V is small enough that O(V²) is safe.

Adjacency List

Each vertex stores only its neighbors
  • Space: O(V+E)
  • Edge lookup: O(deg(u))
  • Neighbor traversal: O(deg(u))
  • Default representation for sparse graphs.
FAANG Interview Trigger This is the standard choice for BFS, DFS, connected components, topological sort, Dijkstra, and most coding interview graph problems.

Edge List

A flat list of edge tuples

Stores edges as pairs or weighted triples. It is compact and convenient when the algorithm processes edges globally.

FAANG Interview Trigger Kruskal’s algorithm starts from an edge list because it sorts all edges by weight.

Incidence Matrix

Rows are vertices; columns are edges

Useful in graph theory, linear algebra formulations, flow networks, and specialized network analysis.

FAANG Interview Trigger Rare in coding interviews. Mention it when discussing alternative representations, but do not default to it for traversal problems.

9. Graph Traversal: DFS vs BFS

Stack depth vs queue layers

Depth-First Search (DFS)

Explore deeply, then backtrack

DFS follows one path as far as possible before backtracking. It uses an explicit stack or the call stack.

  • Cycle detection
  • Topological sorting
  • Connected components
  • Backtracking and path enumeration
FAANG Interview Trigger Choose DFS when the problem asks whether a path exists, requires postorder information, explores all possibilities, or needs recursion-state cycle detection.

Breadth-First Search (BFS)

Visit level by level

BFS explores all neighbors at distance 1, then distance 2, and so on. It uses a queue.

  • Shortest path in unweighted graphs
  • Level-order traversal
  • Multi-source spreading simulations
  • Bipartite checking by level/color
FAANG Interview Trigger Choose BFS when the answer is “minimum number of moves/edges,” when distance grows in layers, or when multiple sources expand simultaneously.

10. Shortest Paths

Choose by edge-weight constraints

Shortest Path in an Unweighted Graph — BFS

First arrival gives minimum edge count
O(V + E)
  1. Start BFS at the source and set its distance to 0.
  2. When first discovering a neighbor, mark it visited and store its parent.
  3. Stop when the destination is reached or continue for all distances.
  4. Reconstruct the path by walking backward through parent pointers.
FAANG Interview Trigger “Minimum moves,” “fewest transformations,” “closest exit,” and “shortest number of flights when each flight counts equally” are BFS signals.
Unweighted / equal costBFS
Non-negative weightsDijkstra with a min-heap
Negative weightsBellman–Ford; detects negative cycles
All pairsFloyd–Warshall, usually O(V³)

Dijkstra’s Algorithm

Single-source shortest paths with non-negative edge weights
O((V+E) log V)
  1. Set the source distance to 0 and every other distance to infinity.
  2. Push the source into a min-priority queue.
  3. Pop the vertex with the smallest tentative distance.
  4. Relax each outgoing edge: update a neighbor when a shorter route is found.
  5. Ignore stale heap entries or mark finalized vertices.
Critical constraint: Dijkstra is not correct when negative-weight edges can produce a later, cheaper route to an already finalized vertex.

11. Spanning Trees and Minimum Spanning Trees

Connect everything without cycles

Spanning Tree

A connected, acyclic subgraph covering all vertices
  • Contains all original vertices.
  • Has exactly V−1 edges.
  • Contains no cycle.
  • A connected graph can have many spanning trees.
FAANG Interview Trigger A spanning tree is about feasibility and structure, not minimum cost. It often appears in network design and proofs about connectivity.

Minimum Spanning Tree (MST)

The spanning tree with minimum total edge weight
  • Defined for weighted, connected, undirected graphs.
  • Has V−1 edges and no cycle.
  • Found using Prim’s or Kruskal’s algorithm.
FAANG Interview Trigger “Connect all cities/computers/points with minimum total cost” is an MST problem—not a shortest-path problem.

Kruskal’s Algorithm

Sort globally; add safe edges
O(E log E)
  1. Sort all edges in ascending weight.
  2. Add the next edge only if its endpoints are in different components.
  3. Use Disjoint Set Union (Union-Find) to detect cycles efficiently.
  4. Stop after selecting V−1 edges.
FAANG Interview Trigger Prefer Kruskal when edges are already listed or sortable, and when the graph may be sparse.

Prim’s Algorithm

Grow one connected tree frontier
O(E log V)
  1. Choose any starting vertex.
  2. Push outgoing edges into a min-heap.
  3. Take the minimum edge that reaches an unvisited vertex.
  4. Add the vertex and expose its outgoing edges.
FAANG Interview Trigger Prefer Prim when working from an adjacency list and growing a single connected component from a chosen start.

12. Detecting a Cycle in a Directed Graph

Visited is not enough

DFS + Recursion State

A back edge to an active vertex proves a cycle
O(V + E)
  1. Start DFS from each unvisited vertex.
  2. Mark the current vertex as visited and active in the recursion path.
  3. If an edge reaches an active vertex, report a cycle.
  4. After exploring all neighbors, remove the vertex from the active path.
boolean dfs(u): state[u] = VISITING for v in graph[u]: if state[v] == VISITING: return true if state[v] == UNVISITED and dfs(v): return true state[u] = VISITED return false
Three-state model:
0 = unvisited
1 = visiting / active
2 = fully processed
FAANG Interview Trigger Course Schedule and dependency-cycle questions can be solved with DFS coloring or Kahn’s topological sort. State why a normal visited set alone cannot distinguish an active ancestor from a fully processed node.
