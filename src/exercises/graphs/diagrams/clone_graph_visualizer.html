Click Play or Next to step through how the imperative DFS algorithm clones nodes and resolves cyclic graph dependencies using the HashMap.

Why `HashMap`? When a neighbor has already been visited (cycle detected), we do NOT call `new Node()`. Instead, we retrieve `visited.get(neighbor)` to connect the existing clone reference safely!

Imperative DFS Approach
public Node cloneGraph(Node node) {
if (node == null || node.neighbors == null) return null;
Node startNode = new Node(node.val);
HashMap<Node, Node> visited = new HashMap<>();
dfs(startNode, node, visited);
return startNode;
}
void dfs(Node startNode, Node originalNode, HashMap<Node, Node> visited) {
visited.put(originalNode, startNode); // Register in map
for (Node neighbor : originalNode.neighbors) {
if (!visited.containsKey(neighbor)) { // Unvisited Neighbor
Node deepNeighbor = new Node(neighbor.val);
startNode.neighbors.add(deepNeighbor);
dfs(deepNeighbor, neighbor, visited);
} else { // Visited Neighbor (Cycle Detected!)
startNode.neighbors.add(visited.get(neighbor)); // Attach existing clone
}
}
}
